# Smooth Curves, Sudden Shocks

This repository holds a working paper, with its analysis code and data, on the gap between smooth
growth in frontier AI capability and stepped public attention and policy.

- `paper/`: the current draft (PDF, Word, Markdown)
- `study-design/`: the study design, coding manual and results so far
- `study/`: code and data (METR break tests; pre-registered attention study)
- `HANDOFF.md`: project status, results and next steps; **start here**

Status: this is a draft and has not yet been submitted. The capability analysis is complete. The
attention analysis has a Wikipedia-only pilot, and its full run needs Google Trends and GDELT data
(`study/run_local.sh`).
